# Independent verification bundle — i(G), µ*(G) and γ(G) on `counterexamples.json`

One folder, self-contained. Everything in `REPORT.md` is regenerated by the four scripts below from `counterexamples.json` alone.

## What is what

| file | role | needed to reproduce? |
|---|---|---|
| `REPORT.md` | the report (Part 1: i and µ*; Part 2: γ + literature placement) | — (output) |
| `counterexamples.json` | **input**: the seven graphs (edges, graph6, pivot matching, CNF `K`, claimed values) | yes |
| `verify_ids.py` | Part 1 engines: graph6 codec, sanity checks, maximal-matching check, i(G) by CBC / HiGHS / own B&B / SAT, µ*(G) by edge-ILP / line-graph B&B, controls, random sweeps. Writes `results.json`. Also the library the other two scripts import. | yes |
| `structural_check.py` | Part 1, engine (d): structural 2²⁰ enumeration for i(G) | yes |
| `verify_gamma.py` | Part 2 engines: γ(G) by CBC / HiGHS / own B&B / SAT / structural, controls, validation. Writes `results_gamma.json`. Imports `verify_ids.py`. | yes |
| `paper_control.py` | Part 2 external control: rebuilds the Theorem-2 graph of arXiv:2608.22498 from its Appendix-A formula, reproduces its certified values, checks uniqueness of the minimum maximal matching in all graphs, isomorphism to `R0+R0`. Imports both scripts above. | yes |
| `pasted_g6.txt` | the graph6 string as it was pasted in the original brief (204 chars, two `_` lost to markdown); optional — `verify_ids.py` skips the check if absent | no |
| `results.json`, `results_gamma.json` | every number and witness from the two batteries (machine-readable) | — (outputs) |
| `run.log`, `structural.log`, `run_gamma.log`, `paper_control.log` | raw console output of the four scripts, as run for the report | — (outputs) |
| `ds_atmost15_R6_R6.cnf`, `ds_atmost15_R6_R7.cnf`, `ds_atmost15_R7_R7.cnf` | DIMACS certificates: "dominating set of size ≤ 15" for the three γ = 16 graphs. Variable v+1 ↔ vertex v (v = 0..49); variables > 50 are sequential-counter auxiliaries. Any SAT solver must answer UNSAT. | optional third-party check |

## How to run (≈ 1–2 min total, single core)

```
pip install pulp python-sat scipy numpy networkx     # networkx only for the isomorphism diagnostic; optional
python3 verify_ids.py counterexamples.json          # Part 1  (~20 s)  -> results.json
python3 structural_check.py counterexamples.json    # Part 1 engine (d) (~12 s)
python3 verify_gamma.py counterexamples.json        # Part 2  (~30 s)  -> results_gamma.json
python3 paper_control.py                            # Part 2 external control (~4 s)
```

Keep the three `.py` files and `counterexamples.json` in the same folder (imports and the input path are relative). pulp ships its own CBC binary; scipy ≥ 1.9 provides HiGHS via `scipy.optimize.milp`; python-sat provides CaDiCaL.

## Headline numbers (details and timings in `REPORT.md`)

* All seven graphs: simple, connected, cubic, n = 50; pivot matching {0,1},…,{28,29} is the **unique** maximal matching of size 15, so µ* = γ_e = 15.
* i(G) = 16 for R3+R3 (= G₁), R3+R6, R3+R7, R6+R6, R6+R7, R7+R7 (refutes i ≤ µ* for regular graphs at r = 3); i(R0+R0) = 15.
* γ(G) = 16 for **R6+R6, R6+R7, R7+R7** (refutes Baste–Fürst–Henning–Mohr–Rautenbach's γ ≤ γ_e for regular graphs at Δ = 3, the case left open by arXiv:2608.22498; n = 50 is the least possible cubic order by its Prop. 7); γ = 14, 15, 15, 14 for R3+R3, R3+R6, R3+R7, R0+R0.
* R0+R0 is isomorphic to the Theorem-2 graph of arXiv:2608.22498 (γ = 14, i = 15, γ_e = 15 — all reproduced).
* Controls: Petersen i = γ = µ* = 3; K₄, K₃,₃, Q₃; brute force on small cubic graphs; 30-graph random agreement sweeps — no mismatches anywhere.
